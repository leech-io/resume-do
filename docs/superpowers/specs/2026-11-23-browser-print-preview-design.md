# 浏览器打印预览设计

## 目标与已确认交互
在编辑页顶栏「下载 PDF」旁新增「打印预览」。用户点击后打开浏览器原生打印预览，可选择打印机或另存为 PDF。

## 方案与取舍
- 已选：直接打印当前浏览器中的 A4 简历分页。复用当前内容、字体及模板，不等待后台 PDF worker。
- 未选：先生成 PDF 再预览。与后台导出文件一致，但需要 worker 和生成等待。
- 实现选择：当前页面通过打印媒体样式只输出主简历预览，不新开窗口或复制一套独立渲染器；便于复用字体和图片资源，避免弹窗拦截。

## 行为与边界
- 打印当前编辑内容和当前预览版式，包括尚未自动保存的编辑；不创建导出任务，不以保存成功为前置条件。
- 打印前等待字体、简历内图片及分页稳定；准备时按钮显示「正在准备…」并禁止重复触发。资源失败或内容溢出时显示可理解的提示，不静默打印缺失或被裁切的简历。
- 使用现有 210mm × 297mm 分页，页面外边距为 0，保留模板本身的页边距。打印时恢复 100% 显示比例，移除页面阴影与屏幕页间距，不产生额外空白页。
- 只打印主简历分页；顶栏、排版工具、编辑区、测量节点、浮动按钮、页数提示、弹窗和通知均不打印。深色界面不改变纸张与模板配色。
- 用户取消或完成打印后，编辑内容、滚动位置和预览缩放不被主动重置，按钮可再次使用；打印准备失败时恢复按钮并允许重试。
- 本期只覆盖结构化简历编辑器，不改变原件预览、现有下载 PDF 和后端接口，不增加依赖。
- README 说明本地打印与后台导出的区别，以及浏览器设置对纸张、缩放、背景图形和页眉页脚的影响；应用不能强制覆盖用户或打印机的设置。

## 验收
1. 按钮位于「下载 PDF」紧邻位置，点击触发一次原生打印。
2. 最新编辑内容、多页内容、照片、单栏/侧栏模板可打印，打印不请求导出 API。
3. 深浅主题与 60%/100% 预览缩放下，打印页面尺寸和分页不变，页面不夹带工作台内容或多余空白页。
4. 资源等待、溢出阻断、准备失败重试、取消后再次打印均有验证。
5. 现有下载 PDF 的相关回归继续通过。
